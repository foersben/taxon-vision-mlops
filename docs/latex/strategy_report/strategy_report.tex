\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
TaxonVision-MLOps establishes an automated, production-grade Machine Learning Operations platform for fine-grained biological species identification. Transitioning away from ad-hoc, notebook-bound model development, this architecture utilizes a unified open-source toolchain (DagsHub, DVC, MLflow, Optuna) mapped to a hybrid compute topology (GitHub Actions and local bare-metal GPU runners). To comply with ethical and regulatory standards, the system enforces epistemic safety via Split Conformal Prediction and Energy-Based Out-of-Distribution (OOD) detection, ensuring mathematical coverage guarantees in production. This document outlines the end-to-end pipeline, testing strategies, and core architectural trade-offs driving the system's design.
