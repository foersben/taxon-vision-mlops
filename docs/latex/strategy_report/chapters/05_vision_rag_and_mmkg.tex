\chapter{Vision RAG \& Multimodal Knowledge Graph}
\label{ch:vision_rag}

Standard text-centric Retrieval-Augmented Generation (RAG) paradigms typically rely on document chunking, token embedding, and semantic similarity search in order to ground large language models. In visual ecology, we must fundamentally transform this concept into multimodal equivalents. Citizen-science platforms aggregate massive volumes of environmental imagery, but raw field photographs are highly dense, noisy, and unstructured. Rather than attempting to compute and search vector embeddings across the entire 170-million-image iNaturalist corpus \cite{vanhorn2018inaturalist}, the TaxonVision-MLOps architecture couples a curated Reference Exemplar Catalogue with single-stage spatio-temporal filtered graph traversal in LanceDB and conformal-driven lazy execution.

\section{Ingestion Engine \& Reference Exemplar Catalogue Curation}
\label{sec:exemplar_curation}

A naive approach to visual retrieval attempts to pass every available field photograph through a deep Vision Foundation Model (VFM) in order to construct an exhaustive vector database. In the context of global biodiversity monitoring, this brute-force strategy requires generating dense embeddings for more than 170 million observations. Storing 768-dimensional 32-bit floating-point (FP32) representations for this volume would require over 520 GB of addressable memory purely to hold the vector matrices in RAM, alongside years of continuous GPU compute on workstation-grade silicon.

The platform actively circumvents this computational barrier by curating a deterministic Reference Exemplar Catalogue. Instead of tracking all historical user submissions, our ingestion pipeline filters raw DarwinCore observation records according to four strict quality predicates:
\begin{enumerate}
    \item \textbf{Validation Tier:} Observations must hold official \texttt{research\_grade} status, confirming agreement across three or more independent community experts.
    \item \textbf{Licence Compliance:} Records must possess open-access metadata headers matching Creative Commons Zero (\texttt{CC0}), Creative Commons Attribution (\texttt{CC-BY}), or Attribution-NonCommercial (\texttt{CC-BY-NC}). Commercial, no-derivative (\texttt{CC-BY-ND}), or copyleft/share-alike variants (\texttt{CC-BY-SA}) are explicitly dropped at the ingestion boundary to eliminate viral licensing constraints on derived model weights.
    \item \textbf{Signal Quality:} Raw candidate photographs must exceed a minimum resolution of $1024 \times 1024$ pixels in original source repositories for exemplar inclusion, whilst the streaming ingestion pipeline pulls $500\text{px}$ medium locators for fast Arrow serialisation. Furthermore, upstream zero-shot object detection must isolate the primary organism with a detection confidence score greater than $0.85$.
    \item \textbf{Diversity Sampling:} The catalogue selects up to 50 exemplar observations per taxon. In order to capture seasonal and geographical morphological variations, observations are partitioned into discrete spatial clusters using Uber H3 hexagonal spatial cells at Resolution 4.
\end{enumerate}

By bounding the catalogue to 2,000 baseline taxa with 50 exemplars each, the vector database maintains an upper bound of 100,000 reference vectors. The total memory required to hold these 768-dimensional FP32 vectors in RAM evaluates to
\[
\text{Memory}_{\text{Vectors}} = 100{,}000 \times 768 \times 4 \text{ bytes} \approx 307.2 \text{ MB}.
\]
Stored as compressed WebP image crops averaging 45 KB each, the total exemplar disk image footprint is approximately 4.5 GB. This architectural decision allows the entire retrieval index to reside in high-speed host RAM, completely eliminating disk I/O bottlenecks during retrieval.

\section{Visual Entity Linking: Parent-Child Chunking}
\label{sec:parent_child_chunking}

In text-based RAG architectures, feeding an entire multi-page document into an embedding model dilutes key semantic signals. Similarly, passing an uncropped field photograph into a Vision Foundation Model introduces severe environmental noise. Background clutter -- such as soil, sky, vegetation, water reflections, or human hands holding a specimen -- dominates the receptive field, creating spurious cosine similarities between taxonomically distant species that inhabit similar macro-environments.

In order to isolate diagnostic visual signals, the system implements Parent-Child Visual Chunking. An upstream zero-shot detector (YOLO-World or OWL-ViT v2) scans the raw photograph to isolate the target specimen, extracting a normalised bounding box $B = [x_{\min}, y_{\min}, x_{\max}, y_{\max}]$. The organism crop ($I_{\text{child}}$) is scaled to $224 \times 224$ pixels and forwarded to the frozen vision backbone (BioCLIP-2 or DINOv3) to produce a unit-normalised visual embedding vector $z_{\text{child}} \in \mathbb{R}^d$ ($d=384$ or $512$):
\[
z_{\text{child}} = \frac{f_{\text{VFM}}(I_{\text{child}})}{\|f_{\text{VFM}}(I_{\text{child}})\|_2},
\]
where $f_{\text{VFM}}$ represents the forward pass of the frozen vision backbone. The original uncropped field photograph ($I_{\text{parent}}$) is preserved as an environmental habitat context layer and cryptographically linked to the child crop via the relational manifest tuple:
\[
\text{EntityLink} = \left\langle \text{CropID}, \text{ParentURI}, B, \text{DarwinCorePayload} \right\rangle.
\]
During vector search, similarity queries execute strictly over child embeddings ($z_{\text{child}}$); upon retrieval for multimodal reasoning, both the child crop and parent context are presented to the evaluator.

\section[Single-Stage Filtered HNSW in LanceDB]{Vector Database: Single-Stage Filtered HNSW in LanceDB}
\label{sec:filtered_hnsw}

Biological retrieval systems face a severe domain-specific failure mode known as \textit{convergent evolution}. Under similar ecological pressures, unrelated organisms across distinct continents frequently evolve nearly identical visual morphologies. For example, the European Hornet (\textit{Vespa crabro}) and the North American Cicada Killer (\textit{Sphecius speciosus}) exhibit strikingly similar body geometry and colouration patterns.

If a retrieval engine implements standard two-stage post-filtering -- performing a global nearest-neighbour vector search first, and then filtering results based on geographical metadata -- the query will fail. If a user in Germany submits a photo of a European wasp, the top-50 visually nearest neighbours returned by an unconstrained vector index might consist entirely of visually indistinguishable American species. Applying a subsequent geographical filter then drops all 50 candidates, resulting in an empty retrieval set and complete context starvation.

In order to resolve this, the architecture adopts \textbf{Single-Stage Metadata-Filtered HNSW} implemented within LanceDB. LanceDB integrates Apache Arrow columnar data structures directly with vector indices, evaluating geographic and temporal boolean constraints natively \textit{during} graph traversal rather than post-retrieval.

Let $\mathbf{x}_{\text{query}} = (\text{lat}_{\text{query}}, \text{lon}_{\text{query}})$ denote the GPS coordinates of the query, and $\tau_{\text{month}} \in \{1, \dots, 12\}$ denote the observation month. For each candidate node $j$ encountered during the HNSW beam search, the traversal engine evaluates the deterministic predicate $\mathcal{P}(j)$:
\[
\mathcal{P}(j) = \left[ \mathcal{D}_{\text{geodesic}}(\mathbf{x}_{\text{query}}, \mathbf{x}_{j}) \le R_{\max} \right] \land \left[ \min\left( |\tau_{\text{month}} - \tau_{j}|, \, 12 - |\tau_{\text{month}} - \tau_{j}| \right) \le \Delta_{\text{season}} \right],
\]
where $\mathcal{D}_{\text{geodesic}}$ is the great-circle geographic distance computed via the Haversine equation, $\mathbf{x}_{j}$ represents the coordinates of exemplar node $j$, $R_{\max} = 500\text{ km}$ is the maximum admissible geographic search radius, $\tau_{j}$ is the historical observation month of exemplar $j$, and $\Delta_{\text{season}} = 1$ enforces a 3-month seasonal window centred on the observation epoch across cyclic year boundaries. If node $j$ violates $\mathcal{P}(j)$, its outgoing edges are pruned immediately, preventing the search from descending into biogeographically invalid graph clusters and guaranteeing 100\% valid retrieval recall in under $5\text{ ms}$.

\section{Conformal-Driven Lazy Execution}
\label{sec:lazy_execution}

Executing zero-shot entity linking, vector graph traversal, and generative multimodal reasoning for every incoming request imposes prohibitive latency and computational costs. In order to maintain an SLA of under $25\text{ ms}$ for high-volume inference, the Vision RAG pipeline utilises conformal-driven lazy execution governed by the 4-tier conformal routing contract:
\begin{enumerate}
    \item \textbf{Decisive Classification ($|\hat{C}(X)| = 1$ with $\hat{\pi}_{\max}(X) \ge \tau_{\text{conf}}$):} The model exhibits high confidence and low epistemic ambiguity ($\hat{\pi}_{\max}(X) \ge \tau_{\text{conf}} = 0.60$). The endpoint dispatches the single predicted taxon immediately, fulfilling the strict sub-$25\text{ ms}$ Service Level Agreement (SLA) without activating retrieval overhead.
    \item \textbf{Moderate Ambiguity ($1 < |\hat{C}(X)| \le k_{\max}$, with $k_{\max} = 3$):} The conformal prediction set contains between two and three plausible sibling taxa. The serving engine executes a single-stage filtered HNSW traversal over LanceDB, constrained by the candidate class identifiers and spatio-temporal metadata, and performs Reciprocal Rank Fusion (RRF) over visual exemplar crops with less than $6\text{ ms}$ overhead to deliver a multi-candidate comparative differential to the operator.
    \item \textbf{Severe Ambiguity or Low Top-1 Confidence ($|\hat{C}(X)| > k_{\max}$ or ($|\hat{C}(X)| = 1 \land \hat{\pi}_{\max}(X) < \tau_{\text{conf}}$)):} The prediction set exceeds the bound of actionable human differential review, or a singleton set fails the minimum confidence threshold ($\hat{\pi}_{\max} < 0.60$). The query is scheduled for asynchronous multimodal resolution via gRPC to the quantised visual language model (\texttt{taxon-vision-vlm}, based on Qwen2-VL-2B) and appended to the Active Learning triage queue (\texttt{triage\_queue.lance}) on SeaweedFS for expert annotation.
    \item \textbf{Epistemic Novelty / Complete Abstention ($|\hat{C}(X)| = 0$):} The observed sample violates the conformal coverage boundary, indicating an out-of-distribution observation, unmodelled developmental instar, or extreme sensor degradation. The system executes complete epistemic abstention, bypasses automated classification entirely, executes an unconstrained nearest-neighbour retrieval over the global exemplar space, and dispatches an immediate priority triage alert to human taxonomists.
\end{enumerate}

\section{Multi-Modal Re-Ranking via Reciprocal Rank Fusion}
\label{sec:rrf_reranking}

Nearest-neighbour vector search establishes raw visual affinity, but visual embeddings alone cannot capture fine morphological traits, such as minor wing venation patterns or subtle genital plate structures. In order to enhance diagnostic relevance, retrieved candidates are re-ranked using Reciprocal Rank Fusion (RRF), integrating visual similarity with empirical biogeographical observation frequencies:
\[
\text{Score}_{\text{RRF}}(i) = \frac{w_{\text{vis}}}{k + r_{\text{vis}}(i)} + \frac{w_{\text{geo}}}{k + r_{\text{geo}}(i)},
\]
where $\text{Score}_{\text{RRF}}(i)$ is the consolidated ranking metric for candidate exemplar $i$, $w_{\text{vis}} = 0.65$ and $w_{\text{geo}} = 0.35$ denote scalar weighting factors for visual cosine similarity and biogeographical occurrence priors respectively, $k = 60$ is a rank-smoothing constant that prevents low-ranking outliers from dominating the fused score, $r_{\text{vis}}(i)$ is the ordinal rank of candidate $i$ sorted descending by cosine similarity $z_{\text{child}} \cdot z_{i}$, and $r_{\text{geo}}(i)$ is the ordinal rank sorted descending by historical observation density $P(y_i \mid \text{Cell}_{\text{H3}}, \tau_{\text{month}})$ derived from pre-indexed GBIF occurrence frequencies.

This rank fusion guarantees that candidates appearing at the top of the context window are both visually representative of the query and frequently documented within that ecological spatio-temporal niche.

\section{Multimodal Context Synthesis \& VLM Diagnostics}
\label{sec:vlm_synthesis}

When severe ambiguity ($|\hat{C}(X)| > k_{\max}$) or low top-1 separation confidence triggers Tier-3 escalation, or when an operator explicitly requests an automated differential diagnosis, the candidate exemplars resulting from Reciprocal Rank Fusion are assembled into a structured prompt schema along with the query observation. This payload is dispatched to a localised Vision-Language Model (such as a quantised Qwen2-VL-2B instance running on host P-cores or the RTX 5070 Ti).

In order to ensure machine readability and eliminate ungrounded generation or conversational drift, the VLM is constrained by grammar-based sampling to emit a strictly typed JSON payload:
\begin{minted}{json}
{
  "conformal_context_size": 2,
  "candidates_evaluated": ["Bombus terrestris", "Bombus lucorum"],
  "primary_discriminator": "Pronotal collar colouration and width",
  "morphological_analysis": "The specimen exhibits a dark buff-yellow abdominal band and brownish-white tail hairs matching Bombus terrestris rather than the bright lemon-yellow band typical of Bombus lucorum.",
  "recommended_taxon": "Bombus terrestris",
  "epistemic_verdict": "HUMAN_TRIAGE_RECOMMENDED",
  "rationale": "High visual overlap under strong sunlight reflection; wing marginal cell venation partially occluded."
}
\end{minted}

This structured response is rendered on the HTMX operator dashboard as a comparative differential diagnosis card. This allows human specialists to inspect aligned visual crops alongside identified discriminative keys.

\section{Operationalising Taxonomic Mutations in the MMKG}
\label{sec:taxonomic_mutations}

The Vision RAG architecture functions as the ingestion engine for human-in-the-loop active learning workflows. When the Vision-Language Model assigns an epistemic verdict of \texttt{HUMAN\_\allowbreak TRIAGE\_\allowbreak RECOMMENDED} to an ambiguous query, the observation and its retrieved visual context are mirrored to the DagsHub Label Studio workspace. Once experts validate the taxonomy, the new annotations expand the training manifests and update the reference exemplar index.

However, beyond classifying new observations, the system must dynamically adapt to Linnaean taxonomic realignments. Biological taxonomies are fluid; the scientific community frequently splits a single species into multiple distinct taxa, or lumps distinct taxa into a single unified classification. Retraining a neural network or recalculating millions of vector embeddings every time a nomenclature committee publishes an update is computationally unviable. 

The Multimodal Knowledge Graph resolves this by decoupling the immutable visual embedding vectors from the mutable relational metadata using the \textbf{DuckDB 2.0.0 LTS} analytical engine (codenamed ``Cinnamon Teal'') operating over LanceDB dataset tables via Apache Arrow zero-copy memory buffers:
\begin{itemize}
    \item \textbf{Taxonomic Lumps (Merging):} When two distinct taxa (e.g., Species A and Species B) are combined into a single valid species (Species C), the pipeline does not re-embed any visual data. Instead, it executes an $\mathcal{O}(1)$ alias mapping operation. A background DuckDB 2.0.0 worker executes an in-place vectorized SQL update on the relational Lance manifest, pointing historical taxon keys for A and B to the unified key for C. The underlying dense vectors residing in the HNSW index remain untouched, updating the taxonomic knowledge base in milliseconds with zero GPU compute overhead.
    \item \textbf{Taxonomic Splits (Dividing):} When a recognised species is divided into two distinct taxa, historical visual crops associated with the parent taxon become scientifically ambiguous. The DuckDB reconciliation worker sets a boolean metadata flag \texttt{requires\_reannotation = true} over those specific records in the Lance table. LanceDB's single-stage filtered HNSW traversal natively excludes nodes where \texttt{requires\_reannotation = true}, preventing contaminated retrieval in production whilst routing the affected exemplars to Label Studio for expert sorting.
\end{itemize}

\section{End-to-End Latency \& Resource Allocation}
\label{sec:latency_budget}

Operating a decoupled serving architecture requires clear engineering resource bounds. To guarantee the overarching sub-$25\text{ ms}$ Service Level Agreement (SLA) on production GPU silicon (NVIDIA RTX 5070 Ti), the platform partitions the execution timeline into bounded budget allocations. Table~\ref{tab:rag_latency} details these engineering budget ceilings across the fast hot-path and the lazy retrieval path.

Crucially, these figures represent allocated architectural SLA ceilings rather than static, universal hardware constants. Physical backbone inference latency varies substantially across execution providers: a domain transformer such as BioCLIP-2 or DINOv3 executes in under $9\text{ ms}$ when compiled with FP16 TensorRT or ONNX Runtime on modern desktop GPU Tensor Cores, but requires $20\text{ to }50\text{ ms}$ or more when deployed on general-purpose CPUs without dedicated SIMD acceleration. Consequently, downstream operational deployments strictly profile candidate extractors dynamically using the Pareto benchmark suite rather than assuming static values from external literature. Furthermore, during active Jenkins GPU training windows, \texttt{taxon-vision-vlm} either scales to zero or offloads inference to the 16 host CPU P-cores and 128~GB system memory, guaranteeing that concurrent serving allocations never exceed the 4.8~GB VRAM reserve derived in Section~\ref{sec:gpu_partitioning}.
